# 관리자 사용 설명서 (교회용)

교회 관리자(교역자·사무간사·재정부)가 어드민(`/admin`)에서 재적·재정을 사용하는 방법.
개발자용 문서는 [README](../README.md), 화면 뒤 동작 원리는 각 기획서 참고.

## 시작 전: 계정과 권한

| 역할 | 얻는 방법 | 할 수 있는 것 |
|---|---|---|
| 교회 관리자 | 교회 신청 승인 시 자동 / 기존 관리자가 이메일 초대 | 콘텐츠·재적·재정 기본 기능 |
| 민감 권한 | 플랫폼 관리자가 부여 (아래) | `members_sensitive`: 목양 메모·심방 기록 / `finance_approve`: 지출 승인·마감·예산 저장·영수증 발급 |

- 권한 부여(플랫폼 관리자): `PUT /api/churches/:id/admins/:userId/permissions`
  body `{ "permKey": "finance_approve", "status": "allowed" }` (해제는 `"status": null`)
- 특정 메뉴만 차단하려면 `"status": "denied"` (기본 기능은 차단된 사람만 막는 방식)

## 재적 (교인 관리)

### 교인 관리 — `/admin/members`
- 등록·수정·검색(이름/상태/직분/신급/가족 필터), 페이지네이션
- 연락처·주소는 서버에 **암호화 저장**되고 화면에서만 복호화 표시
- **엑셀 가져오기**: 기존 교적 엑셀(이름/연락처/직분… 컬럼 자동 인식) 업로드 → 실패 행 리포트
- **엑셀 내보내기**: 전체 명단 다운로드 — 데이터는 언제든 가져갈 수 있습니다

### 조직 관리 — `/admin/members/groups`
- 교구>구역>셀, 부서, 팀을 트리로 구성. 조직별 명단·리더 지정
- 한 교인이 여러 조직에 속할 수 있음

### 출석 체크 — `/admin/members/attendance`
- 예배/모임(세션)과 날짜를 고르고 명단에서 탭하여 체크 (모바일 최적화)
- 통계: 예배별 추이, 개인별 이력

### 새가족 정착 — `/admin/members/newcomers`
- 등록 → 새가족반 → 수료 → 정착 **칸반 보드**. 카드를 끌어 단계 이동, 담당자 지정
- 경과일이 표시되어 정착이 늦어지는 새가족이 눈에 띕니다

### 심방 관리 — `/admin/members/visitations`
- 요청(사유 공개) → 배정 → 완료. **심방 기록 내용은 교역자 권한자만** 읽고 쓸 수 있음
- 목양 메모: 교인별 비공개 기록 — 열람도 감사 로그에 남습니다

### 대시보드 — `/admin`
- 재적 현황, **장기결석 감지**(N주 미출석 active 교인), 이번 주 생일, 새가족 현황

## 재정 (회계)

> 원칙: 입력은 **헌금(계수)** 과 **지출결의** 두 곳뿐 — 장부·보고서는 전부 자동 집계.
> 금전 기록은 수정·삭제가 없습니다. 잘못 입력은 **사유와 함께 취소 후 재입력** (감사 대비).

### 주일 루틴: 헌금 계수 — `/admin/finance/offerings`
1. 예배 후 **계수 시작** (날짜·예배·계수자 2인 기입)
2. 봉투 순서대로: 헌금 종류 버튼 → 금액 → 헌금자 이름(자동완성으로 교적 연결, 비우면 무기명) → **Enter**
   - 종류는 유지되고 봉투번호는 자동 증가 — 같은 종류 연속 입력에 최적화
3. **계수 완료** → 계수표(종류별·방법별 합계) 확인 → **확정** (이후 입력 불가, 취소만 가능)

### 지출: 지출결의 — `/admin/finance/expenses`
1. **기안**: 부서·항목·금액·제목 + 영수증 사진 첨부 (연번 자동: 2026-001)
   - 연간 예산을 넘으면 경고가 뜹니다 (차단은 아님)
2. **승인/반려**: `finance_approve` 권한자(재정부장·담임) — 반려는 사유 필수
3. **지급 처리**: 지급일·방법 기록 → 이후 수정·취소 불가

### 예산 — `/admin/finance/budget`
- 지출 항목별 연간 예산 입력 → 저장(승인 권한). 집행률 막대와 잔액이 자동 표시

### 장부·월 마감 — `/admin/finance/ledger`
- 기간별 헌금 내역과 종류별 집계, 취소 건 표시 토글
- **월 마감**: 월 버튼을 눌러 잠금(승인 권한) — 잠긴 월은 입력·취소·지급이 차단됩니다.
  정정이 필요하면 마감 해제 후 처리 (잠금·해제 모두 기록에 남음)

### 보고서 — `/admin/finance/reports`
- **월간 보고**(제직회용): 전월 이월 → 수입 → 지출 → 월말 잔액 자동 계산, 인쇄 버튼
- **주보용 요약**: 주일 날짜 선택 → 종류별 합계 배지 (주보에 그대로 옮기면 됨)
- **재정 투명성 공개**: 켜면 교회 홈페이지 `/transparency`에서 누구나 월간 요약(집계만) 열람

### 기부금영수증 — `/admin/finance/receipts` (연말)
1. **단체 정보** 입력 (단체명·세무서 고유번호) — 최초 1회
2. 귀속 연도 선택 → 교인별 연간 합계 확인 → 주민번호 입력(선택) → **일괄 발급**
   - 주민번호는 암호화 저장, 화면에는 마스킹만 표시
3. 발급 대장에서 **인쇄**(영수증 양식) / 잘못 발급은 **취소** 후 재발급
4. **국세청 제출 파일** 다운로드 — 주민번호가 있는 영수증만 포함
   ⚠️ 홈택스 제출 전 그해 전산매체 스펙과 대조 확인 필요

## 자주 묻는 것

- **승인 버튼이 403이에요** → `finance_approve` 권한이 없는 계정입니다. 권한 부여 필요
- **마감된 달에 헌금을 넣어야 해요** → 장부 화면에서 해당 월 잠금 해제 → 입력 → 다시 마감
- **교인 이름이 자동완성에 안 떠요** → 재적에 먼저 등록돼 있어야 합니다 (또는 이름만 적으면 미연결로 기록)
- **개인별 헌금 내역은 누가 보나요** → 재정 권한자만. 교역자라도 재적 권한만으로는 볼 수 없습니다
